## 一、结构：三个学习单元 + 折叠进阶区

### 为什么脱离通用模板

通用模板的区块顺序假定一页只处理一个问题。这一页压着三个只松散相连的问题，套进模板的结果是：
读者在见到任何一个基本立场之前，先撞上整张「心理因果与排除论证」图（因果完备性、过度决定、二维语义学、罗素式一元论），
而那张图第一分支就叫「个例同一论式物理主义」——这个名称在本页此前从未界定。

新增 `mind-self-entry.tsx`（手写教学主线），与《存在与变化》共用 `teaching-entry.module.css`
（原名 `being-change-entry.module.css`，本轮 `git mv` 改名，因为它不再专属一页）。

`node-content.tsx` 里原来写死 `if (node.id === 'pt-being-change')`，本轮改成一个两项的 `handwritten` 描述：
`body`（渲染哪条正文）与 `tailArgument` / `tailExperiment`（论证地图和思想实验交给共享尾部，还是由正文自己安排位置）。
mind-self 两样都自己安排。

### 渲染顺序（本地版本，实测标题序列）

```
本页范围 → 读这一页之前 → 具体入口（那份承诺）→ 问题起点
→ 先把问题拆开（概念卡，id="concepts"）
→ 一、我为什么还是原来的我？（判准一／二／三）
→ 二、感觉与身体是什么关系？（物理主义／心身二元论／功能主义）
→ 三、是否必须有一个不变的我？
→ 有力反对及回应 → 哲学家怎样改写这个问题 → 案例推演 → 思想实验 → 容易混淆的地方
→ 进阶：两场更技术的争论（折叠）
→ 人物与原典 → 迁移练习
→ 跨传统的可比问题 → 放回历史线索 → 回到问题 → 带着问题继续读 → 继续学习 → 研究层
```

### 三个单元各自的交接

- **单元一**收在「三条判准里有两条都在讲『心理』，可心理本身是什么样的东西？这个问题不回答，那条链究竟是什么在连着，就是空的」。
- **单元二**收在「三条路线争的是心理状态是什么，但它们都默认了有一个人在拥有这些状态。这个默认本身没有被问过」。
- **单元三**开头就界定被质疑的那个「我」，并明写它不是前两单元的第三个选项。

### 进阶区怎么分的

| 内容 | 去向 | 理由 |
| --- | --- | --- |
| 心理因果与排除论证（整张图） | 进阶甲（折叠） | 要用到完备性、过度决定、个例同一，三者都在主线之后才具备 |
| 可设想性、二维语义学、初级／次级、罗素式一元论 | 进阶甲（图内的分支） | 它们本来就是该图「个例同一论式物理主义」一栏的反对与回应 |
| 类型／个例／功能／还原的精细关系 | 进阶乙（折叠） | 主线只需要「不排成一条直线」这个结论，论证可以后置 |
| 人格同一性四问的完整列举 | 进阶乙 | 主线只用到持续问题这一问 |

进阶区**不是把旧文本折起来**：甲块外面新写了三段铺垫（它在解决什么、需要你已经有什么、三栏是并列不是递进）；
乙块把来源账里的 `boundaries` 三段接进来，外面新写了铺垫和一段还原论／物理主义的分别。
两块开头都写明**可以跳过，跳过之后主线仍然完整**。

## 二、八条概念与推理订正

每条写成「原文 → 问题 → 改后 → 落在哪个文件」。

### 1. 记忆判准的强度（变量 B）

- **原文**：「按『能记得就是同一个人』，四十岁的他与二十岁的他是同一个……」
- **问题**：没有区分充分条件、必要条件、双条件，反驳落点不明；也看不出它是否一并打掉心理连续性理论。
- **改后**：先摆出（甲）充分／（乙）必要／（丙）双条件三种读法，再走矛盾——按（甲）得出前两段同一，按（乙）得出首尾不同一，
  而同一关系必须传递，所以两条不能同时要。`tests` 补一句：这条反驳打中的是（乙）（丙）那一版，
  换成「一环扣一环的链」就绕开了传递性难题。
- **落点**：`thought-experiments.ts` 变量 B 第一问与 `tests`；`mind-self-entry.tsx` 判准一。
- **三时点**：原本就有（20／40／70 岁），未改。

### 2. 器官置换（变量 C）

- **原文**：`changed: '断裂的一侧：这次断掉的是身体，不是心理。'`
- **问题**：把结论写进了设定。材料更换并不自动中断生物体的持续，所以这个案例打不到它声称要打的判准上。
- **改后**：`changed` 改为「换掉的是身体的质料，心理完整保留」；`tests` 先挡住「质料换光＝换了生物体」这一误推
  （身体判准要求的是同一套生命过程没有中断，而分次置换期间这套过程一直在运转），再说明它真正检验的是
  「你那条判准是否偷偷要求了原材料同一」；另加一问，请读者说出要真正压到生物体判准上该怎样改写案例。
- **落点**：`thought-experiments.ts` 变量 C 的 `changed`、`questions`、`tests` 与「身体与生物体的持续」那条原则；
  `mind-self-entry.tsx` 判准三。

### 3. 随附 ≠ 副现象论

- **原文**：「改主张心理属性随附于物理属性……**但心理不再反过来推动物理**。」
- **问题**：从随附直接读出了因果无效，中间整条论证被跳过。
- **改后**：随附只讲依赖关系，主张心理有因果效力的人同样可以接受它；副现象论是另一个立场，
  在中文文献里它是排除论证逼出来的一个出口。正文还补了一句中文词的陷阱：「随附」两个字容易被读成「附属、附带」。
- **落点**：`data.json` 心身二元论的 `response`；`mind-self-entry.tsx` 单元二二元论「还空着什么」。

### 4. 理论分类

- **原文**：立场名「物理主义／自然主义」；论证路径「类型同一论最强，功能主义只要求……还原论要求……」。
- **问题**：物理主义与自然主义并成一个名称；功能主义被当成强弱等级里的一档。后者还与同一页的来源账直接冲突。
- **改后**：立场改名为「物理主义」（`positionArguments` 的键同步改，构建期校验通过）；
  第三步改写为按「各自回答哪个问题」分类——类型／个例同一论答「在哪一层上同一」，还原论答「心理解释能否被顶替」，
  功能主义答「心理状态由什么来定」；并写明功能主义与个例同一论并存。
  共享概念卡「功能主义」新增一条与个例同一论的区分（该卡同时挂在 AI 那一页上）。
- **落点**：`data.json`、`study-guides.ts`、`concepts.ts`、`mind-self-entry.tsx` 单元二与进阶乙。

### 5. 知识差异 ≠ 存在差异

- **原文**：只写「依赖两条可以被单独攻击的前提」。
- **改后**：拆成四级——（一）目前还不知道／（二）说尽物理描述仍不知道／（三）原则上不可能由物理描述给出／
  （四）因此存在非物理事实；并点明（三）→（四）是从「某类知识」跨到「某类事实」，还要额外用上
  「物理事实是完全的、封闭的、独占的」这条物理主义自带的界定。
- **落点**：`study-guides.ts` 心身二元论第二步；`mind-self-entry.tsx` 单元二末尾。

### 6. 疼痛的位置

- **原文**：「一次疼痛既没有形状也没有位置——你不能问它有几厘米宽。」
- **问题**：断言比中文文献能支持的更强；同一处还从「两类描述说不到一起」直接走到「有两个东西」。
- **改后**：分开三件事——被感到的位置（左手拇指那一处）、引起它的身体过程的位置、这次体验本身能否被第三方在公共空间中定位；
  反对栏补出「从描述之别走到存在之别需要另外的论证」。
- **落点**：`data.json` 心身二元论的 `text` 与 `objection`；`mind-self-entry.tsx` 单元二开头。

### 7. 责任案例

- **原文**：「三者对同一性的要求依次更强」；「它只要求当初立约的那个法律主体还在」。
- **改后**：拆成四件独立的事——（一）人格是否持续／（二）识别证据／（三）履行能力／（四）规范判断，
  并写明义务内容改变的是（三），对（一）的要求是同一个；「把义务更难履行写成同一性要求更强，是把第三问混进了第一问」。
  「完整走一遍」改成六步分段（定住问题 → 暂时判断 → 依据 → 反对 → 回应 → 限制），
  法律部分明确标为**案例设定**，并附一句「真实法律中一份承诺在失能之后如何处理，取决于具体法域与文书形式，本页不作判断」。
- **落点**：`study-guides.ts` caseStudy 第二、三、五问。

### 8. 总结与立场呈现

- **原文**：「那一步至今没有人补上」；「无我一路欠一个不靠不变主体的连接方式」。
- **改后**：改为「至今没有被普遍接受的补法——**不是没有人提出过**」，并把双方各自已有的几条方案列出来；
  无我一侧改为「欠的是从各派竞争的连接方案里定下一个」，并在 `objections` 里按汉译原典写出各部派各自主张什么。
- **落点**：`content-ledger.ts` takeaway 的 `split` 与 `open`、`objections` 第二段。

### 被中文资料挡回去的三处（原稿或候选写法有误）

1. **不写「常一主宰出自某部论」**。本轮做了 CBETA 全藏检索：该四字连用全藏仅 15 条，最早见于唐·道邑《成唯识论义蕴》，
   《成唯识论》《成唯识论述记》《俱舍论》正文均无。所以正文写的是「汉传注疏归纳出来的说法」。
2. **规格是四项不是三项**。道邑把「主」与「宰」分开解（自在／割断），原稿的「能作主宰」合并了两项。
3. **不写「疼痛没有位置」**。见 MS-11。

### 查到但本轮未采纳、也未写进正文的分歧

- **「无我」与「非我」之争**：汉译《杂阿含》以「非我」为主（第 33 经作「色非是我」、第 34 经作「色非有我」，
  同一经内「非是我」与「无我」并用）。这条分歧只写进了 MS-6 的来源说明，正文没有展开——
  要展开须先处理巴利三句与汉译三句的对位，而这个对位在中文文献里本身有两种不同的配法。
